# EMRY Extension Icons

Place your icon files here:
- `icon16.png` (16x16)
- `icon48.png` (48x48)
- `icon128.png` (128x128)

You can generate icons from any brain/memory emoji or design.

For now, you can use any PNG images, or generate them online at:
- https://favicon.io/
- https://realfavicongenerator.net/

Suggested icon theme: A brain (🧠) or memory chip design with purple/blue gradient colors.
